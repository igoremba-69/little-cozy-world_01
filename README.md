# Little Cozy World — clean rebuild

Это полностью пересобранная классическая версия.

Главное исправление: контур и цветовой слой разделены на два canvas. Заливка проверяет чёрные линии отдельно, поэтому цвет не зависит от того, насколько антиалиасингом обработана исходная картинка. Кисть использует выбранный цвет, а ластик работает через прозрачность.

Откройте `index.html` или загрузите файл на GitHub Pages. Для iPhone используйте HTTPS-адрес GitHub Pages.
